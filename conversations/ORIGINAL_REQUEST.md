# Solicitud original del usuario

**Fecha:** 2026-07-21T20:55:36Z

## Objetivo

Rediseñar, optimizar y potenciar `millabogados.com` en una aplicación web interactiva ultrarrápida, segura, grado $10,000 USD usando Vite, React, Three.js (React Three Fiber) y GSAP.

## Requisitos

### R1. Preservación absoluta de marca
- 100% del contenido original, diseño de página, anclas de navegación (`#firma`, `#servicios`, `#equipo`, `#diferenciadores`, `#asesoria-virtual`, `#contacto`)
- Textos legales, logos, paleta de colores, tipografía dual (Cormorant Garamond + Manrope)

### R2. Three.js WebGL 3D interactivo
- Escultura geométrica 3D de mármol y oro ("Equilibrio 01") con materiales PBR
- Reflejos suaves, iluminación destacada, interacción parallax 360° con cursor/touch
- Partículas de oro flotantes

### R3. Rendimiento ultrarrápido
- Vite con code splitting, lazy loading, optimización WebGL para 60fps
- Precarga de Google Fonts, cero scripts bloqueantes

### R4. Seguridad y formulario
- Validación client-side del "Buzón Jurídico" con generación de folio (`FOLIO-YYYYMMDD-XXXX`)
- Defensa honeypot anti-spam, sanitización XSS, manejo seguro de estado del formulario
