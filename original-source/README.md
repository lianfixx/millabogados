# Archivos de referencia — Premium Version y Original Source

Las versiones completas de referencia están disponibles en:
- `premium-version/` — Versión HTML estática premium con GSAP + Three.js (CDN)
- `original-source/` — HTML fuente original extraído del navegador

Debido al tamaño de algunos archivos (>60KB), se recomienda consultar las copias locales.
Los archivos principales y funcionales están en la raíz del repositorio:
- `index.html` — Página principal completa
- `styles.css` — CSS premium 
- `app.js` — Motor de animaciones
- `sculpture3d.js` — Escultura 3D
- `server.mjs` — Servidor de desarrollo
